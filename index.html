家族の記録を、ちょうどいい時間に届ける。

音声・テキスト・写真として積み重なっていく家庭の記憶を、検索できて、通知で思い出せて、 AIが寄り添って答えてくれる場所に。私たちKairosは、そのアプリと管理画面を 「仕様通りに、そして気持ちよく動く形」で仕上げるパートナーです。

PROJECT UNDERSTANDING

これは、ただの受託案件ではないと考えています。

画面構成・データ項目・デザイン案はすでに固まっている。だからこそ求められているのは 「言われた通りに作る実装力」ではなく、「家庭の繊細な情報を扱う責任を理解した実装の丁寧さ」だと受け止めています。

家族ごとの切り替え・プッシュ通知・AI検索 ー これらは単なる機能リストではなく、「誰かが毎日ふと開くアプリ」として 違和感なく動くことが前提になる機能だと理解しています。通知が来る時刻、 AIが返す答えの的確さまで含めて、使う人の体験として作り込みます。
音声の録音・アップロード・自動文字起こし ー Whisper / Gemini APIでの文字起こしは精度とコストのバランスが鍵になります。 データ量や更新頻度を踏まえ、現実的な構成をご提案します。
Googleフォーム × Apps Script ー 運営のオペレーションに既に組み込まれている仕組みを壊さず、 アプリ・管理画面側にスムーズに橋渡しする設計が必要だと理解しています。

WHAT KAIROS BRINGS

Kairosがご提供できること

進行管理とお客様対応は御社にお任せいただき、私たちは開発に集中します。 そのうえで、次の5点を強みとしてご提案します。

01

iOS / Android 同時開発

Flutter / React Nativeによるクロスプラットフォーム開発と、App Store・Google Playへの申請まで一貫して対応します。

02

Firebase / Supabase 設計

家族単位のデータ構造、認証、プッシュ通知基盤を、スピードと堅牢さの両立を意識して構築します。

03

AI・音声APIの実装経験

Gemini / OpenAI APIでの文字起こし、質問に合うデータを返すAI検索機能など、外部APIを組み込んだ開発に対応しています。

04

Googleフォーム連携

Apps Scriptによる回答の自動取り込みなど、既存の運営フローを崩さない外部連携を設計・実装します。

05

Next.js管理画面 + API開発

データ管理・CSV入出力・会員管理まで、運営者が迷わず使える管理画面をReact/Next.jsで構築します。
